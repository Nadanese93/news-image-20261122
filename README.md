A one-page world-news front page for Sunday 22 November 2026, drawn
procedurally by `main.py` (Python 3.13 standard library only) as a
1024×1024 PNG.

**Headlines:** the Gulf war widens (IRGC: two U.S. drones down, tanker
hit off Oman, Hormuz traffic down 65%); Russia's biggest air attack on
Ukraine (400 drones, 110 missiles, debris in Poland); COP31 deadlocked
over fossil fuels; a 6.9 quake hits the Andes in Peru; Trump, Xi and
Putin meet in Shenzhen; cartel boss 'El Chapo Isidro' held in Mexico;
oil down 3%, Bolsonaro in ICU.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.png
```

Deterministic: repeated runs write byte-identical output. No network,
no files read.
